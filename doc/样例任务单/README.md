## 上传登记时怎么填

- **文档类别**：现有词表里选「方案」最接近；想更准可以先在「元数据词表」加一个「生产任务单」。
- **客户名称**：01–04 对应词表里已有的华东理工、南方药业；05–10 的客户不在词表里，
  可以留空，或在「元数据词表 → 客户名称」里把它们加进去（加进去后台账检索也认）。
- **项目编号**：01–04 按上表填，填了之后这些文档会挂到对应项目下，
  方案生成选基准项目时能顺着文档继承内容。
- **密级**：内部即可。

## 几点说明

- 这些文件保留了内容控件（和模板版同一套 Tag），所以既能当语料，也能直接另存为新模板；
  当语料上传不受影响，解析取的是文字。
- 解析需要真实解析服务：内置演示解析器只认纯文本，docx 要接上 MinerU（在线或本地）才解析得了。
- 数据是为测试编的：客户、人名、价格、日期均为虚构，01–04 的参数与台账里已有的项目对得上，
  其余是按常见工况配的。

生成脚本见本目录 `make_samples.py`（从模板版 docx 重新生成，改数据后可再跑）。
