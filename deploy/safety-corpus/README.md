# 安全事故案例语料（公开资料）

## CSB 事故调查报告（`csb_reports.json` + `import_csb.py`）

美国化学品安全委员会（U.S. Chemical Safety and Hazard Investigation Board，csb.gov）的事故调查报告，只挑了和我们产品相关的：反应失控、聚合失控、过氧化物分解、釜内超压。

- **许可**：CSB 是美国联邦政府机构，报告是公有领域作品，可以放进知识库、翻译、引用。引用时写明「美国化学品安全委员会（CSB）调查报告」。
- **PDF 不进 git**：每份 2–20 MB，导入时从 csb.gov 下载（服务器上不了的话，在别的电脑下载好拷过去，用 `--dir`）。
- **导进哪里**：知识库「安全事故案例（公开资料）」（没有会自动建），密级「公开」，文档类别「资料」，设备类型「反应釜」，客户名称「公开资料（美国 CSB）」，标题是中文。
- **助手怎么用**：「反应热安全评估」「危险工艺与危化品」两个技能里写了：讲风险、讲为什么要配联锁和泄放时，搜同类工艺的 CSB 事故引用。

用法见 `import_csb.py` 开头，或部署文档第 17 节。
