# PPT 模板库（内置）

30 套演示模板，来自 SlidesCarnival（https://www.slidescarnival.com），许可 CC BY 4.0。2026-11-22 下载。

- `templates.json`：每套的中文名、风格标签、页数、用到的字体、原始网址、许可、署名。
- `*.pptx`：模板文件（不进 git，许可不许原样转发；部署时从开发机拷到服务器）。图片已压缩（最长边 1600 像素，不透明的照片改存 JPEG），版式和内容没改。
- `previews/`：封面缩略图（本机预览用，不进 git；服务器上导入时会重新转）。

## 许可要点（SlidesCarnival 模板许可）

- 可以商用、可以改，用模板做出来的 PPT 可以发给客户。
- 要署名：做出来的 PPT 里保留一行「Presentation template by SlidesCarnival」，或者保留模板自带的 Credits 页。
- 模板里的照片有各自的许可：用了模板自带的照片，就要保留 Credits 页。
- **不许把模板文件原样转发、再提供下载**（哪怕免费）。所以系统里只用来套内容，不给「下载空模板」的按钮。

## 字体

模板用的都是 Google Fonts 里的开源字体（OFL / Apache）。中文要另配：服务器上装思源黑体（Noto Sans SC，OFL），中文字自动换成它。
