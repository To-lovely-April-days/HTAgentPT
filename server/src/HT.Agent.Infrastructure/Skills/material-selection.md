# 选材与耐腐蚀

<!-- 初稿按行业通用知识写，公司经验由技术部补充；标 [待填] 的必须填 -->

## 先确认（缺了先按常见情况答，并写明假设）
- 介质主成分和浓度；杂质：Cl⁻、F⁻、Fe³⁺/Cu²⁺ 等氧化性离子、H₂S
- 操作温度和最高温度、压力；有没有温度波动、冷凝
- 氧化性还是还原性环境，是否充气或除氧
- 流速、固体颗粒（冲刷）；是否有食品、药品等洁净要求

## 怎么判断
1. 先用 query_projects、search_documents 查公司同工况的项目和故障案例，有现成经验的优先，说明是哪个项目
2. 按介质性质初筛：还原性酸、氧化性酸、含氯、含氟、高温氢、强碱，各类介质的常用材料不同
3. 有腐蚀数据的写出数值、单位 mm/a 和出处；可用 / 慎用 / 不推荐的界限按公司规定 [待填]
4. 给出推荐材料和一个备选；备选和推荐的材料成本差用 search_prices 查

## 常见的坑（必须提醒）
- 母材耐蚀不等于焊缝耐蚀：热影响区容易点蚀，焊后要酸洗钝化
- 少量氧化性杂质会让镍基合金在盐酸里明显加速腐蚀
- 316L 在含氯介质、温度较高时有点蚀和应力腐蚀开裂风险
- 温度升高，腐蚀速率可能成倍增加，不能拿常温数据套高温工况
- 衬里、涂层方案要考虑破损后的后果和检修方式

## 该查什么
search_documents（选材案例、腐蚀数据表、材料手册）· query_projects（同工况项目）· search_prices（给备选时附成本差）· chemical_info（介质性质）

## 回答怎么写
结论（推荐材料和适用条件）→ 依据（公司案例、数据都带出处）→ 风险提醒 → 要向客户确认的参数 → 备选方案和材料成本差
