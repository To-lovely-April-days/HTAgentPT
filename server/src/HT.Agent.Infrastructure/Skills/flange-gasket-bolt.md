# 法兰垫片紧固件

## 先确认
- 设计压力、设计温度、介质（是否易燃、有毒、强腐蚀）
- 公称尺寸 DN；配对管道或设备用的是哪个标准体系
- 法兰材质、管子外径系列

## 怎么选（具体数值查标准，用 search_standards）
1. 标准体系：HG/T 20592～20614 是欧洲体系（PN 系列），HG/T 20615～20635 是美洲体系（Class 系列）。两套尺寸不通用，配对的两片法兰必须同一体系、同一系列
2. 压力等级：按法兰材料组别，在标准的压力-温度额定值表里查设计温度下的允许工作压力，要不低于设计压力
3. 密封面：一般用突面 RF；易燃、有毒或要求更严的用凹凸面 MFM、榫槽面 TG；高压用环连接面 RJ；与铸铁或非金属件配对用全平面 FF
4. 垫片：低压、强腐蚀可用聚四氟乙烯包覆垫；中高压、温度波动大的用带内外环的缠绕垫；环连接面用金属环垫。垫片材料要和介质、温度相配
5. 紧固件：按标准选专用级或商品级；中高压、高温用全螺纹螺柱，材料与温度匹配
6. 规格写法按对应标准里的「标记」示例写（标准号、法兰类型、公称尺寸、公称压力、密封面、材料等）

## 常见的坑
- HG/T 20592 有 A、B 两个管子外径系列（英制管、公制管），选错了对不上管子
- PN 和 Class 不能直接换算后混配
- 高温下法兰允许压力明显下降，不能只看常温
- 螺栓拧紧要按对角顺序、分几次拧到位
