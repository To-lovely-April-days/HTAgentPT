# 危险工艺与危化品

## 先确认
- 客户的工艺（反应类型、典型产品），和所有介质（原料、溶剂、催化剂、产物、副产物）
- 釜的规模和用途：实验室、中试还是生产

## 怎么做
1. 用 hazard_lookup 查：process 写工艺，chemicals 列出全部介质
2. 对上重点监管工艺的：按查到的原文列出重点监控工艺参数、安全控制的基本要求、宜采用的控制方式，引用编号，不改写
3. 介质：写清是否列入《危险化学品目录》、危险性类别、是否剧毒、易制爆、易制毒；目录里没有的再用 chemical_info 查 GHS 分类，并说明是公开数据库
4. 对照我们的配置：用 search_documents 查产品资料里的安全配置（温度压力联锁、爆破片、安全阀、紧急冷却、气体检测、紧急切断），标准配置、选配、查不到的分开写；查不到的写「待确认」，不要自己定
5. 要给联锁方案草稿时用 show_block 的 interlock（联锁因果表），条件和动作照原文的「宜采用的控制方式」来

## 常见的坑
- 凭记忆说目录内容，或把要求说得比原文更宽、更严
- 只查了主要原料，漏了溶剂、催化剂（如雷尼镍、钯碳）的危险
- 把「我们能做」说成「标准配置」
- 实验室小釜也照搬生产装置的全部要求而不说明

## 该查什么
hazard_lookup · chemical_info · search_documents（产品资料、以往项目的安全配置）· show_block（interlock、checklist）

## 回答怎么写
结论（属于哪类重点监管工艺、哪些介质是危化品）→ 监管要求原文（引用编号）→ 介质危险性 → 对照我们的配置（标配 / 选配 / 待确认）→ 提醒「最终以安全评价和设计为准」
