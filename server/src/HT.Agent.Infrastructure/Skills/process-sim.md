# 流程模拟（DWSIM）

## 先确认
- 流程：有哪些设备、怎么连（进料 → 反应 → 换热 → 分离……）
- 进料：温度、压力（表压）、流量、组成
- 每台设备的条件：出口温度或热负荷、出口压力、转化率
- 体系有没有电解质、聚合物、固体（这些 DWSIM 算不好，直接说明，不硬算）

## 怎么做
1. 用 process_sim 一次给出整个流程；改条件就改描述再调一次
2. 物性方法：
   - 烃类、轻气体（氢气、氮气、甲烷）、高压：Peng-Robinson (PR) 或 Soave-Redlich-Kwong (SRK)
   - 含水、醇、酸等极性物质的液相：NRTL 或 UNIQUAC（低压）
   - 纯水和蒸汽：Steam Tables (IAPWS-IF97)
   - 回答里写清选了哪个、为什么
3. 组成按质量分率给；手上是摩尔分率就先用 calculate 换算
4. 转化反应器：转化率是给定条件（来自用户、文献或经验），不是算出来的；反应相一般用 Mixture
5. 闪蒸罐、反应器的出口：第 1 股气相、第 2 股液相
6. 报错时按 DWSIM 的原话改；改 3 次还不行就停下来，说清卡在哪
7. 算完：反应器、冷却器的能量流是撤走的热，加热器的是加进去的热，泵和压缩机的是功率
8. 要接着选设备时，用算出的热负荷、流量、温度压力，按「设备选型答复」「夹套换热」技能往下做

## 常见的坑
- 压力写成绝压（我们统一用表压）
- 循环（回流、循环气）第一版不能算：把循环断开，用估计的循环量当进料，并说明
- 精馏塔第一版不能算：用 run_python 做简捷估算（Fenske、Underwood），并说明
- 把模拟结果说成实测值；转化率、效率这些假设不写出来

## 该查什么
process_sim · calculate · run_python · hazard_lookup（工艺是否重点监管）· search_documents（以往项目的工艺条件）

## 回答怎么写
结论（关键物流和负荷）→ 流程图和物流表（系统已显示）→ 物性方法和理由 → 给定的条件和假设 → 提醒「模拟估算，正式设计请工艺工程师核对；DWSIM 文件可下载核对」
