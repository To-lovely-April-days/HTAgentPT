# 询价需求澄清

## 先确认
- 客户原话或附件里已经给了什么（逐条摘出来，照原文写）
- 是新设备、改造还是备件；数量

## 怎么做
1. 用 query_projects 查这个客户以往的项目，能补上的信息先补上（注明来自哪个项目）
2. 按下面几类列已知项和缺项：
   - 工艺：用途、介质、反应类型、间歇或连续
   - 设备：容积、设计压力和温度、材质、搅拌、密封、加热冷却
   - 控制：控温精度、仪表、数据记录、联锁、防爆要求
   - 附件：取样、加料、冷凝回流、过滤、支架或推车
   - 商务：数量、交期、交货地点、安装调试、是否含税
   - 资质：压力容器监检、第三方检测、出口资料
3. 缺项分三级：必须（不知道就报不了价）、重要（影响方案）、可以后补
4. 用 inquiry_form 生成缺项单，每个缺项写一句为什么要问、常见的选法
5. 能先按常见情况估的，写出假设，让客户确认就行，不要什么都问

## 常见的坑
- 一次问太多，客户不回；只问必须和重要的
- 客户给的压力没说表压还是绝压、温度没说是操作还是设计
- 把客户的口语说法当成技术参数（如「耐高温」），要换成具体数值来问

## 该查什么
inquiry_form · query_projects（客户以往项目）· search_documents（询价单模板、标准配置）

## 回答怎么写
先说结论（目前能不能报价、还缺几项关键信息）→ inquiry_form 缺项单 → 已按常见情况做的假设 → 一段可以直接发给客户的确认话术
