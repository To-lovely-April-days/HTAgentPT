# 客户研究资料转选型

## 先确认
- 客户要做什么：重复实验、放大（放大到多大）、还是中试
- 资料是哪几份；有好几个方案时，客户要按哪一个

## 怎么做
1. read_attachments 读客户的资料；图片、扫描件用 view_image 或 ocr_image
2. 提取工艺条件，每条标三种状态之一，并写页码或表号：
   - 明确：资料里原文写了
   - 推算：资料没直接写，由其他数推出来（写清怎么推的，如「按 100 g 苯酚、溶剂比 1:20 推算约 3 L」）
   - 没写：要问客户
3. 用 show_block 的 datasheet 列工艺条件（数值后写来源），不要改客户的数
4. 用 hazard_lookup 查工艺和介质（是否重点监管工艺、危化品）
5. 选型：按「设备选型答复」技能，最高温度、压力留余量；放大时装料系数、搅拌、换热要重新核；用 show_block 的 match 对照需求和推荐型号
6. 「没写」的项用 inquiry_form 列成询价缺项单（取样、加热方式、防爆、控制要求、材质特殊要求等），客户可以填完发回来
7. 需要时接着出技术协议

## 常见的坑
- 把推算的数写成客户给的
- 替客户定工艺（只按资料选设备，工艺问题建议客户确认）
- 实验室条件直接当放大条件，没提醒放大后换热、搅拌、安全要求会变
- 漏看资料里的图表（条件常在图注、表格里）

## 该查什么
read_attachments · view_image · ocr_image · hazard_lookup · show_block（datasheet、match）· inquiry_form · query_projects、search_documents（同类产品和项目）

## 回答怎么写
一句话结论（推荐型号）→ 提取的工艺条件（明确 / 推算 / 没写）→ 选型和理由 → 安全要求 → 询价缺项单
