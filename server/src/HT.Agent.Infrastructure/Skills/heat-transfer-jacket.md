# 换热与夹套

## 先确认
- 物料量、比热（不知道用「物性查询」查）、初温和目标温度
- 加热或冷却方式：导热油、蒸汽、热水、冷却水、冷冻液，以及介质温度
- 夹套或盘管的传热面积（没有就按釜的尺寸估）；有没有反应放热

## 怎么算（用 run_python，ht 库算对数平均温差和传热系数关联式）
1. 间歇加热（热媒温度不变）：t = m·cp / (U·A) · ln[(Ts − T0)/(Ts − T)]；冷却同理
2. 换热量 Q = U·A·ΔTm，ΔTm 用对数平均温差（ht.LMTD）
3. 总传热系数 U 估算用（实际以计算或实测为准，写明是估值）：
   - 蒸汽加热水溶液：约 400–900 W/(m²·K)
   - 导热油加热：约 150–400 W/(m²·K)
   - 冷却水冷却有机物：约 150–400 W/(m²·K)
   - 物料粘度高、搅拌弱时取低值
4. 需要更准时用 ht 库的夹套关联式（如 ht.Lehrer）按流量和物性算夹套侧传热系数

计算模板：
```python
import math, ht
m, cp = 40.0, 4180.0         # 釜内物料质量 kg、比热 J/(kg·K)
U, A = 400.0, 0.8            # 总传热系数 W/(m²·K)（估值）、夹套传热面积 m²
Ts, T0, T1 = 180.0, 25.0, 150.0   # 热媒温度（恒温）、初温、目标温度 ℃
t = m*cp/(U*A)*math.log((Ts-T0)/(Ts-T1))
print(f"加热时间约 {t/60:.0f} min（热媒恒温、忽略热损失和反应热）")
print(f"对数平均温差（逆流，热媒 180→170、物料 25→150）{ht.LMTD(Thi=180, Tho=170, Tci=25, Tco=150):.1f} K")
```

## 常见的坑
- 釜壁、搪玻璃层、结垢都会让 U 大幅下降
- 放热反应要算最大放热速率下撤热够不够，这关系到安全
- 导热油温度高，注意闪点和油的使用温度上限

## 该查什么
run_python · search_documents（公司同类釜的实测升温时间）· chemical_info
