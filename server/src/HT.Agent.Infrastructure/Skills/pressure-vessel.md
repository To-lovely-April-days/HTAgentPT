# 压力容器基础

## 先确认
- 最高工作压力、设计压力（表压）、设计温度；内径、容积
- 介质（是否易爆、毒性程度）；材料和焊接接头形式、无损检测比例
- 腐蚀裕量

## 是不是压力容器（TSG 21，以现行原文为准，用 search_standards 核对）
同时满足下面三条的属于固定式压力容器：工作压力 ≥ 0.1 MPa；容积 ≥ 0.03 m³ 且内直径 ≥ 150 mm；介质为气体、液化气体，或最高工作温度 ≥ 其标准沸点的液体。类别（Ⅰ、Ⅱ、Ⅲ）按介质分组和压力 × 容积查规程附录的分类图。

## 怎么算（GB/T 150，用 run_python 或 calculate 算，列出公式和代入）
- 圆筒计算厚度：δ = pc·Di / (2[σ]ᵗ·φ − pc)
- 标准椭圆封头（2:1）：δ = pc·Di / (2[σ]ᵗ·φ − 0.5·pc)
- 设计厚度 = δ + C2（腐蚀裕量）；名义厚度 = 设计厚度 + C1（钢板负偏差）后向上圆整到钢板规格
- 最小厚度：碳素钢、低合金钢不小于 3 mm；高合金钢不小于 2 mm（不含腐蚀裕量）
- 焊接接头系数 φ：双面焊对接全部无损检测 1.0、局部 0.85；单面焊全部 0.9、局部 0.8
- 液压试验压力：pT = 1.25·p·[σ]/[σ]ᵗ；气压试验：pT = 1.10·p·[σ]/[σ]ᵗ
- 试验时圆筒应力 σT = pT(Di + δe)/(2δe)，液压不超过 0.9·ReL·φ，气压不超过 0.8·ReL·φ

许用应力 [σ]ᵗ、屈服强度 ReL 只能从公司标准库里查 GB/T 150.2 的表（search_standards）；查不到就请用户提供，不能凭记忆填。

计算模板（run_python，示例数字要换成实际值）：
```python
pc, Di, phi = 1.6, 500, 1.0          # MPa、mm、焊接接头系数
s_t, s_20 = 137.0, 137.0             # 设计温度、试验温度下的许用应力 MPa（查 GB/T 150.2）
C1, C2 = 0.3, 1.0                    # 钢板负偏差、腐蚀裕量 mm
d = pc*Di/(2*s_t*phi - pc)
print(f"圆筒计算厚度 {d:.2f} mm，设计厚度 {d+C2:.2f} mm，名义厚度至少 {d+C2+C1:.2f} mm（向上圆整）")
print(f"液压试验压力 {1.25*pc*s_20/s_t:.2f} MPa")
```

## 常见的坑
- 设计压力不低于安全阀整定压力；有真空工况的要按外压另算
- 名义厚度还要满足制造、刚度和最小厚度要求
- 计算结果只是估算，正式设计以有资质的设计单位出的计算书为准
