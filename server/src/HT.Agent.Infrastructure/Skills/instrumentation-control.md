# 仪表与自控

## 先确认
- 要测、要控的参数：温度、压力、流量、液位、成分
- 介质、量程、精度；就地显示还是进控制系统（DCS、PLC）
- 是否涉及安全联锁、防爆区域

## 位号怎么写（HG/T 20505，和 ISA 5.1 一致）
- 第一个字母是被测变量：T 温度、P 压力、F 流量、L 液位、A 分析、S 速度、W 重量
- 后面的字母是功能：I 指示、R 记录、C 控制、T 变送、A 报警（H 高、L 低）、S 开关、E 检测元件、V 阀、Y 运算或转换
- 例：TIC-101 温度指示控制，PT-102 压力变送器，LAH-103 液位高报警，PSV 安全阀
- 同一回路用同一个编号

## 怎么判断
1. 测量方式：温度常用热电阻（中低温、精度高）或热电偶（高温）；压力用压力变送器，就地用压力表；液位按介质选差压、雷达、磁翻板；流量按介质和精度选电磁、涡街、质量流量计
2. 控制回路：被控变量 → 控制器 → 执行机构（调节阀、加热功率）。釜温控制常用加热和冷却分程控制
3. 联锁：超温、超压、液位高等危险工况自动切断加热或进料。联锁要独立于控制回路（用独立的测量点）
4. SIL（安全完整性等级）按 IEC 61511 / GB/T 21109，要通过 HAZOP、LOPA 这类评估来定，不能拍脑袋

## 常见的坑
- 控制和联锁共用一个测温点，测点坏了两个都失效
- 量程选得太大，正常工况读数在量程的很小一段，精度差
- 防爆区域的仪表要有防爆合格证

## 该查什么
search_standards（HG/T 20505、GB/T 21109）· search_documents（公司仪表选型、以往项目的仪表清单）· show_block（interlock 联锁因果表）

## 回答怎么写
结论 → show_table 仪表清单（位号、被测变量、测量方式、量程、安装位置、去向）→ 联锁用 show_block 的 interlock 因果表 → 提醒「联锁和 SIL 以 HAZOP、SIL 评估为准」
