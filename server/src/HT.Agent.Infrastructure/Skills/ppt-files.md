# PPT 方案汇报

<!-- 改编自 anthropics/skills 的 pptx 技能（Apache-2.0）：先定提纲、一页一个意思；做法换成我们的模板库和 make_ppt -->

## 先确认
- 给谁讲、讲多久（10 分钟约 8–12 页）、要不要放价格
- 内容来源：方案、参数、案例先查清楚，PPT 里的数字都要有出处
- 公司名写「上海霍桐实验仪器有限公司」，不要编 Logo 和口号
- 用户在输入框选了模板就用它；没选按场景挑：给客户的方案、报价用商务或工业类，内部汇报用简约类，技术交流用科技类

## 怎么做
1. 先列提纲：封面 → 目录 → 需求 → 方案要点 → 主要参数 → 配置对比 → 案例 → 交付与售后 → 结尾，一页一个意思
2. 每页选一种页面类型，写好内容，用 make_ppt 交过去（不要用 run_python 写 python-pptx）：

| 类型 | 用在 | 写什么 |
|---|---|---|
| cover | 封面 | title（项目名）、subtitle（公司名 · 日期） |
| toc | 目录 | items：每项只写 title |
| section | 章节过渡页 | title、subtitle |
| list | 要点 | bullets：3–6 条，每条 30 字以内 |
| items | 几个并列的点（方案要点、步骤、优势） | items：2–6 栏，每栏 title 8 字以内 + text 30 字以内 |
| num | 关键参数、大数字 | numbers：2–4 个，value 带单位（10 MPa），label 说是什么 |
| table | 配置对比、参数表 | rows：第一行表头，最多 8 行 5 列 |
| img | 案例、现场照片 | bullets + image（对话附件里的图片文件名，不给就用模板自带的图） |
| end | 结尾 | title「谢谢」、subtitle 公司名和联系方式 |

3. 系统按类型从模板里挑样页、换字、检查，回来会说哪些页放不下、哪页换了类型：放不下的拆页或删减后再做一次（同一个 file_name）
4. 用户说「换个风格」「换成某某模板」：make_ppt 的 redo 写上一份文件名、template 写新模板，内容不变

## 常见的坑（必须避开）
- 字太多：标题 12 字以内，要点每条 30 字以内，一页最多 6 条；宁可多一页
- 表格超过 8 行就拆两页
- 不要编参数、案例和客户名；查不到的写「待确认」，并在回答里说
- 价格、交期、承诺类内容发客户前要人工确认，在回答里提醒
- 模板是开源模板（CC BY 4.0），最后一页右下角的署名不要让用户删

## 该查什么
search_documents（方案、产品资料）· query_projects（案例）· list_catalog（产品规格）· search_prices（要放价格时）

## 回答怎么写
说明一共几页、每页讲什么（一行一页），哪些数字需要员工核对；用的哪套模板；文件在卡片上看每一页、下载，不满意可以点「换个风格」。
