# 计算书写法

## 先确认
- 算什么、给谁看（内部估算，还是要交给客户或审查）
- 输入参数齐不齐，每个参数从哪来

## 原则
计算一律用 calculate 或 run_python 算，不心算；结果要能让别人照着复核。

## 计算书的结构
1. 计算目的和范围：算什么、对哪台设备、什么工况
2. 依据：标准和条款（用 search_standards 核对编号和名称）、公司资料
3. 输入：每个参数写数值、单位、来源（客户提供、标准查表、公司资料、假设）
4. 公式：写出公式和符号含义
5. 代入和结果：代入数值，写出中间结果和最终结果，单位统一
6. 校核：结果和允许值比较，写「合格」或「不合格」
7. 结论和说明：结论、假设、适用范围、需要复核的地方

## 怎么写
- 用 show_block 的 formula 展示每一步（formula 公式、vars 各量的符号、名称、取值、出处、result 结果）
- 多个计算项用 show_table 汇总
- 单位统一用国际单位，压力写明表压还是绝压

## 常见的坑
- 输入参数没有来源，别人没法复核
- 中间结果四舍五入太早，累积误差
- 用了标准里的系数却没写版本

## 该查什么
calculate · run_python · search_standards · show_block（formula）

## 回答怎么写
结论在前 → 按上面的结构逐节写 → 结尾写「本计算为估算，正式计算以有资质的设计单位为准」（涉及压力容器、安全泄放时必须写）
