# 搅拌与密封

## 先确认
- 物料粘度、密度；是均相、气液、固液还是液液
- 釜内径、液位高度、有没有挡板；要求的转速范围
- 压力、温度、介质（是否易燃、有毒、含氢）

## 怎么判断
1. 搅拌形式：低粘度（约 1 Pa·s 以下）用推进式、斜叶、涡轮；气液分散用涡轮（如 Rushton）；高粘度用锚式、框式、螺带式
2. 功率按功率准数法估（湍流区 Re > 10⁴）：P = Np·ρ·N³·D⁵。高粘度层流区不能用这个式子，要按层流关联式或参考公司同类项目
3. 扭矩 T = P / (2πN)；电机功率在搅拌功率上留余量（传动效率、启动、粘度变化）
4. 密封：高压、含氢、有毒、易燃介质一般用磁力耦合（零泄漏）；磁力耦合额定扭矩留 1.5 倍以上余量，高温要有冷却，磁钢耐温要够（高温用钐钴磁钢）。机械密封适合大扭矩、高粘度，要配冲洗或密封液系统
5. 公司磁力耦合、电机的型号和额定值用 search_documents 查产品手册；同类配置用 query_projects 查

计算模板（run_python，数字换成实际值）：
```python
import math
rho, mu = 1000.0, 0.001      # 物料密度 kg/m³、粘度 Pa·s
N, D = 300/60, 0.15          # 转速 r/s（300 r/min）、桨径 m
Np = 1.3                     # 功率准数：四叶 45° 斜叶 ≈1.3、Rushton 涡轮 ≈5、推进式 ≈0.35（有挡板、湍流）
Re = rho*N*D**2/mu
P = Np*rho*N**3*D**5         # W（湍流区 Re>1e4 才适用）
T = P/(2*math.pi*N)          # 轴扭矩 N·m
print(f"Re {Re:.0f}，搅拌功率 {P:.0f} W，扭矩 {T:.2f} N·m")
print(f"电机功率按 1.3 倍以上（含传动效率和启动）：{P*1.3/1000:.2f} kW；磁力耦合额定扭矩至少 {T*1.5:.2f} N·m（留 1.5 倍）")
```

## 常见的坑
- 功率准数取值和有没有挡板、桨叶数、离底距离有关，写明取值和出处
- 高粘度物料、反应中粘度上升时，按最高粘度核扭矩
- 磁力耦合过载会打滑、长期过热会退磁
