# 设备选型答复

## 先确认（缺了先按常见情况答，写明假设；缺得多就用 inquiry_form 列缺项单）
- 用途：反应类型（加氢、氧化、聚合、萃取……）；间歇还是连续；实验、中试还是生产
- 容积：要的是全容积还是工作容积
- 设计压力、设计温度；操作压力、温度范围；表压还是绝压
- 介质：物料、溶剂、催化剂；有没有氢气、腐蚀性介质、固体颗粒
- 搅拌：粘度范围；气液、固液还是液液混合；转速要求
- 加热和冷却：电加热、导热油、蒸汽、循环水；升温、降温速率
- 密封：磁力耦合还是机械密封；允不允许微量泄漏
- 控制与仪表：控温精度，压力、液位、取样、数据记录、联锁
- 场地：防爆区域、电源；是否属于压力容器、要不要监检取证

## 怎么判断
1. 先用 query_projects、search_documents 查公司做过的相近项目（容积、压力温度、介质相近）。有现成配置的就以它为底稿，说明哪里不一样
2. 容积：装料按全容积的 70%–80% 估；易起泡、反应剧烈的按 60% 左右。公司项目里有实际数据的以项目为准
3. 材质按介质定，必要时翻看「选材与耐腐蚀」
4. 密封：高压、含氢、有毒或易燃介质，一般优先磁力耦合；粘度高、扭矩大的，按「搅拌与密封」算扭矩，核对磁力耦合额定扭矩留够余量。公司磁力耦合型号的扭矩用 search_documents 查产品手册
5. 搅拌形式按粘度和混合要求选：推进式、涡轮式适合低粘度，锚式、框式、螺带式适合高粘度
6. 加热方式按温度和升温速率选。操作温度超过约 250 ℃ 时，要专门核对密封、磁钢耐温（高温用钐钴磁钢）和电机散热
7. 设计压力一般取最高工作压力的 1.05–1.1 倍，且不低于安全阀整定压力
8. 是否属于压力容器按 TSG 21 判断（翻看「压力容器基础」）；属于的，提醒监检、取证对交期的影响

## 常见的坑
- 客户只给「最高压力」，没说是操作压力还是设计压力，要问清
- 含氢介质：注意氢脆和密封泄漏，安全阀出口要引到安全处
- 小容积高压釜的管口有限，加料、取样、测温、安全阀、压力表的接口要早确认
- 控温精度和升温速率的要求可能互相矛盾，要先说清
- 不替公司承诺交期和价格

## 该查什么
query_projects（同类项目）· search_documents（技术方案、技术协议、产品手册）· search_prices（主要材料价）· ask_user（理解有分歧、会影响方案时）

## 回答怎么写
结论（推荐配置一句话）→ 用 show_table 列配置表（容积、设计压力和温度、材质、搅拌、密封、加热冷却、仪表控制）→ 参考的公司项目（带出处）→ 要客户确认的参数 → 可选项及对交期、成本的影响
