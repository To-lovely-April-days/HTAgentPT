# 设备选型答复

<!-- 初稿按行业通用知识写，公司经验由技术部补充；标 [待填] 的必须填 -->

## 先确认（缺了先按常见情况答，写明假设；缺得多就用 inquiry_form 列缺项单）
- 用途：反应类型（加氢、氧化、聚合、萃取……）、间歇还是连续、实验 / 中试 / 生产
- 容积：工作容积和装料系数（按公司惯例 [待填]）
- 设计压力、设计温度，以及操作压力、温度范围；表压还是绝压要分清
- 介质：主要物料、溶剂、催化剂，是否含氢气、腐蚀性介质、固体颗粒
- 搅拌：粘度范围、是否气液或固液混合、转速要求
- 加热和冷却：电加热 / 导热油 / 蒸汽 / 循环水，升温降温速率要求
- 密封：磁力耦合还是机械密封；是否允许微量泄漏
- 控制与仪表：控温精度、压力、液位、取样、数据记录、联锁
- 场地与认证：防爆区域、电源；是否属于压力容器、要不要监检取证

## 怎么判断
1. 先用 query_projects、search_documents 查公司做过的相近项目（容积、压力温度、介质相近），有现成配置的以它为底稿，说明哪里不一样
2. 材质按介质定，必要时翻看「选材与耐腐蚀」技能
3. 密封：高压、含氢、有毒易燃介质一般优先磁力耦合；高粘度、大扭矩时核对磁力耦合扭矩够不够 [待填：公司磁力耦合型号与额定扭矩表]
4. 搅拌形式按粘度和混合要求选（推进式、涡轮式、锚式、框式、螺带式……）
5. 加热方式按温度和升温速率选；高温工况注意密封和电机散热 [待填：公司对高温的界定]
6. 压力和容积决定是否属于压力容器管理范围，属于的要提醒监检、取证对交期的影响

## 常见的坑
- 只给了「最高压力」，没说是操作压力还是设计压力；设计压力要在操作压力上留余量
- 含氢介质：注意氢脆和密封泄漏，安全阀出口要引到安全处
- 小容积高压釜的管口有限，加料、取样、测温、安全阀的接口要早确认
- 控温精度和升温速率的要求可能互相矛盾，要先说清

## 该查什么
query_projects（同类项目）· search_documents（技术方案、技术协议、产品手册）· search_prices（主要材料价）· ask_user（理解有分歧、会影响方案时）

## 回答怎么写
结论（推荐配置一句话）→ 用 show_table 列配置表（容积、设计压力 / 温度、材质、搅拌、密封、加热冷却、仪表控制）→ 参考的公司项目（带出处）→ 要客户确认的参数 → 可选项及对交期、成本的影响
