# 故障排查

<!-- 初稿按行业通用知识写，公司常见故障由售后补充；标 [待填] 的必须填 -->

## 安全第一（写在回答最前面）
涉及泄漏、超压、超温、可燃或有毒介质时，先写安全处置：停止加热和进料、按规程泄压降温、断电、通风，必要时撤离；不要带压拆检。

## 先确认
- 设备型号 / 设备号、使用年限（可以用 query_projects 查设备档案）
- 现象：什么时候出现、持续还是间歇、有没有报警代码、仪表读数
- 工况：介质、温度压力、转速；最近有没有改变操作或更换零件
- 已经做过哪些检查

## 怎么排查
1. 用 search_documents 查同型号的故障案例、维修报告、产品手册里的故障表；有完全对得上的，先照它说
2. 按「先易后难、先外后内、先电后机」排查，每一步写清怎么查、看到什么说明什么
3. 常见方向（公司常见故障清单 [待填]）：
   - 温度：传感器、温控参数、加热元件、冷却水
   - 压力：压力表或传感器、泄漏点、安全阀是否起跳
   - 搅拌：电机、减速机、磁力耦合是否退磁或打滑、轴承
   - 密封泄漏：密封件老化、法兰紧固、密封面损伤
4. 需要换件的列出备件名称和规格；需要上门的说明

## 常见的坑
- 别凭现象直接下结论，先排除仪表本身的问题
- 磁力耦合长期过热会退磁，高温工况要核对
- 提醒客户不要自行拆检带压设备

## 该查什么
search_documents（故障案例、手册、维修报告）· query_projects（设备档案）· ask_user（缺关键现象时）

## 回答怎么写
安全提示（如有）→ 最可能的原因（带依据）→ 用 show_block 的 fault_tree 或 steps 列排查步骤 → 需要的备件 → 处理不了时怎么联系售后 [待填：售后电话和流程]
