# 故障排查

## 安全第一（写在回答最前面）
涉及泄漏、超压、超温、可燃或有毒介质时，先写安全处置：停止加热和进料、按规程泄压降温、断电、通风，必要时撤离。不要带压拆检。

## 先确认
- 设备型号或设备号、使用年限（用 query_projects 查设备档案和项目）
- 现象：什么时候出现、持续还是间歇、有没有报警代码、仪表读数
- 工况：介质、温度压力、转速；最近有没有改变操作或更换零件
- 已经做过哪些检查

## 怎么排查
1. 用 search_documents 查同型号的故障案例、维修报告、产品手册里的故障表。有完全对得上的，先照它说
2. 按「先易后难、先外后内、先电后机」排查。每一步写清怎么查、看到什么说明什么
3. 常见方向：
   - 温度不准或升不上去：温度传感器和接线、温控参数、加热元件、冷却水是否误开
   - 压力异常：压力表或变送器、泄漏点（用检漏液查法兰、接头）、安全阀是否起跳或内漏
   - 搅拌不转或打滑：电机和电源、减速机、磁力耦合退磁或打滑（物料太粘、转速过高）、轴承
   - 密封泄漏：密封件老化、法兰螺栓没按对角顺序拧紧、密封面损伤
   - 异响：轴承磨损、搅拌器碰壁、联轴器松动
4. 需要换件的列出备件名称和规格；需要上门的说明原因

## 常见的坑
- 别凭现象直接下结论，先排除仪表本身的问题
- 磁力耦合长期过热会退磁，高温工况要核对冷却水
- 提醒客户不要自行拆检带压设备
- 改了参数临时好了，也要找到根本原因

## 该查什么
search_documents（故障案例、手册、维修报告、售后服务说明）· query_projects（设备档案）· ask_user（缺关键现象时）

## 回答怎么写
安全提示（有危险时用 show_block 的 callout）→ 最可能的原因（带依据）→ 用 show_block 的 fault_tree（症状、可能原因、可能性高中低、怎么查、怎么处理、相关案例）或 steps 列排查步骤 → 需要的备件 → 处理不了时联系售后：联系方式按公司售后服务说明（search_documents 查），查不到就请客户联系对接的销售或售后负责人
