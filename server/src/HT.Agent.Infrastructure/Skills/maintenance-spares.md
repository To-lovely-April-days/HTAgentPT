# 维护保养与备件

## 先确认
- 设备型号或设备号、使用年限、使用频率和工况（介质、温度压力）
- 问的是日常保养、定期检修还是某个零件

## 怎么做
1. 先用 search_documents 查产品手册里的维护保养章节和备件清单；用 query_projects 查这台设备的项目和维修记录
2. 保养内容按类别整理：
   - 每次使用前后：密封面清洁、检漏、仪表读数是否正常
   - 定期：密封件、垫片检查更换；搅拌轴承、减速机润滑；磁力耦合冷却水路
   - 法定检验：压力容器定期检验、安全阀校验、压力表检定（按规程周期）
3. 备件：写清名称、规格型号、材质、数量；易损件（密封件、垫片、轴承）建议常备
4. 公司手册里没有的周期，按「使用频率高、介质苛刻的缩短周期」给建议，并写明是一般做法

## 常见的坑
- 不同介质的密封件材质不同，换件时不能随便替代
- 安全阀、压力表到期不校验，属于违规
- 自行拆检带压、带温设备

## 该查什么
search_documents（手册、维保记录、备件清单）· query_projects（设备档案）· search_prices（备件价格，有权限才看得到）

## 回答怎么写
结论 → show_block 的 checklist（保养项、周期、说明）→ show_table 备件清单（名称、规格、材质、数量）→ 法定检验提醒 → 需要上门服务时怎么联系（按公司售后服务说明）
