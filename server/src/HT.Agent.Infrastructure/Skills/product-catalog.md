# 霍桐产品目录

## 先确认
- 问的是实验室小型设备、中试 / 生产釜，还是定制成套装置
- 参数以官网公开范围为准；具体型号配置以产品手册、技术协议为准（官网注明「产品配置参数仅供参考，实际配置以实物为准」），可以用 search_documents 查产品手册核对

## 实验室小型设备（官网「小型设备」）
- 微型反应釜：桌面式，反应器和加热控制单元可分离。F 系列法兰式 10ml–2000ml，300℃ & 10MPa；K 系列快开 50–500ml，300℃ & 10MPa；Y 系列一键快开 50–500ml，10MPa（温度官网两处写 250℃ 和 200℃，对外前核对手册）。标配 316L，可定制哈氏、蒙乃尔、因科镍、钛、锆；磁子搅拌或机械搅拌（磁力耦合密封，最高 1000rpm）；HT 款按键、ZN 款触摸屏（可接压力传感器、质量流量计、进料泵，USB 导出数据）。型号如 ZN-250YJ
- 平行反应釜：4–6 工位，50–500ml；使用 300℃ / 10MPa（设计 350℃ / 12.5MPa），B 款使用 200℃；同温或独立控温，PLC 触摸屏或电脑控制，超温超压报警联锁。型号 HT-PXA、HT-PXB、HT-PXC
- 自动升降反应釜：框架式，釜盖固定、管线不用每次拆；用于催化、聚合、超临界、高温高压合成、加氢。案例 1L（-20–200℃，10MPa，油浴）、2L 全透明（RT–150℃，1.5MPa）
- 特色反应釜（声、光、电）：超声波反应釜（20KHZ，300W，100–500ml，2–10MPa）；光化学反应釜（氙灯、汞灯、LED 等光源，高压或常压，蓝宝石视窗）；电化学反应釜（最高 300℃、10MPa）
- 水热反应釜（消解罐）：15–500ml，-0.1–3MPa，聚四氟内衬到 220℃、对位聚苯内衬到 250℃，304 外套
- 玻璃反应釜：双层高硼硅玻璃，10–100L，高温 250℃ / 低温 -80℃（配循环装置），常压或负压
- 平行合成仪：HT-PS6（6×250ml）、HT-PS12（12×50ml）、HT-PS6-A，RT–180℃
- 浸渍提拉镀膜机：HTDC-300、HTDC-300M（多工位），溶胶-凝胶法制膜
- 均相反应器、连续流反应装置（固定床、微通道、连续流硝化、CSTR、管式、光催化、静态混合器、转盘萃取塔、薄膜蒸发器、分子蒸馏器等）

## 生产中试釜（官网「生产中试釜」，可定制）
- 加氢反应釜、平盖催化加氢釜：5–30000L，0–350℃，0–15MPa，磁力耦合密封，自吸式搅拌、气体分布器，防爆电机
- 高压反应釜：5–30000L；材质碳锰钢、不锈钢、锆、镍基合金、钛等；电、热水、导热油、远红外加热
- 中试搅拌高压反应釜：10–100L，316L，RT–350℃，-0.1–10MPa，含进料、导热油控温、联锁控制
- 聚酯聚合反应釜合成装置：5–200L，-0.1–30MPa，-30–350℃，磁力耦合，撬装、自动升降，可配高温出料、切粒
- 不锈钢反应釜（最大 50000L）、高压储罐（1–50000L，0.1–10MPa，-196–220℃）、列管式换热器（1–100㎡）

## 定制案例（官网）
连续反应设备、锂电池反应装置（在线 pH 联锁控制）、中试反应装置、纳米材料 / 量子点反应釜、酯化缩聚反应釜、尼龙聚酯成套反应釜、水处理反应装置、催化湿式氧化装置（300℃、10MPa）、PVC 反应装置、全透明反应釜、固定床反应装置。

## 怎么用
- 客户问「你们能不能做」：先对上面的产品线，再用 query_projects、search_documents 找做过的相近项目；超出范围的说明「可以非标定制，需要评估」，不直接拒绝也不直接承诺
- 具体选型翻看「设备选型答复」，报价翻看「报价答复与成本估算」

## 该查什么
search_documents（产品手册、样本、技术方案）· query_projects · use_skill（设备选型答复）

## 回答怎么写
先说有没有、属于哪条产品线 → 列出相关型号和官网参数范围（写明「以产品手册为准」）→ 相近的定制案例 → 下一步（要哪些参数来选型）
