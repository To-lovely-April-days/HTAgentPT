# 报价答复与成本估算

## 先确认
- 配置是否已定（容积、压力温度、材质、搅拌密封、加热、控制、附件）。没定就先用 inquiry_form 生成缺项单，不急着报数
- 数量、交货地点；是否含运输、安装调试、培训
- 是否含税；付款方式；期望交期
- 是否需要压力容器监检、第三方检测、出口资料

## 怎么做
1. 用 query_projects 查同类项目的合同金额（有权限才看得到），作为参考区间，并说明配置差异
2. 估材料成本：先用 search_prices 逐项查材料、零件价，再用 cost_estimate 列出各项用量和金额。用量按价格的计价单位给
3. 查不到价格的项也要列上，标「待采购询价」
4. 只用查到的价格；不估人工、加工和利润，回答里写明「只含材料成本」
5. 报价口径、折扣、交期承诺按公司报价流程走：用 search_documents 查报价管理规定、标准交期一类文件；查不到就提醒找销售负责人确认

## 常见的坑
- 价格库标了「可能过时」的，提醒找采购确认
- 镍基合金、钛材价格波动大，写明价格日期
- 客户只问「大概多少钱」时，给区间和前提，不给单一数字
- 助手只出内部估算，对外报价以审批后的报价单为准
- 别把内部进价、合同金额写进给客户的文字里

## 该查什么
query_projects · search_prices · cost_estimate · inquiry_form · search_documents（报价单模板、标准配置报价、报价规定）

## 回答怎么写
结论（参考区间或材料成本合计，写明口径）→ show_table 成本明细（项目、规格、用量、单价、金额、来源）→ 参考项目 → 没价格的项 → 要确认的事项 → 提醒「对外报价以审批后的报价单为准」
