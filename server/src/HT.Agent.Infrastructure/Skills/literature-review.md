# 文献调研

## 先确认
- 调研什么：反应或工艺、产品；关心的是条件、催化剂、收率，还是设备和放大
- 调研的用途：给客户选型、写方案，还是内部了解（决定最后落到哪）

## 怎么做
1. search_literature 中英文各查一轮（英文关键词效果更好）；要读具体条件时再加 full_text_only 查一轮有开放全文的
2. 先看摘要挑出相关的 5–10 篇；要具体条件的，用 fetch_url 打开开放全文读（focus 写「反应温度 压力 催化剂 溶剂 收率 反应器」）
3. 篇数多时用 delegate 分头读，每个子任务读 2–3 篇，交回：催化剂、溶剂、温度、压力、时间、结果、反应器
4. 用 show_table（compare 样式）列对比表，每行一篇，最后一列写「读了全文」或「只读了摘要」
5. 统计条件范围（温度、压力、常用催化剂、放大到多大），用 show_block 的 metrics 展示
6. 用途是选型时，把范围翻译成对釜的要求：设计压力、设计温度留余量，搅拌形式（气液固三相要气体分散），材质；再用 query_projects、search_documents 找我们做过的类似项目
7. 专利常有工业放大的条件，和论文分开看

## 常见的坑
- 只读了摘要就写具体条件（摘要常常不写全，要标出来）
- 文献的结论说成我们公司的经验
- 把固定床、连续流的条件套到间歇釜上
- 只查到一两篇就下「一般都这样」的结论

## 该查什么
search_literature · fetch_url · delegate · show_table · show_block（metrics）· query_projects、search_documents（我们做过的类似项目）

## 回答怎么写
一句话结论（主流做法和条件范围）→ 对比表 → 条件范围 → 对选型的意思（用途是选型时）→ 说明检索了多少篇、读了几篇全文、哪些只读了摘要
