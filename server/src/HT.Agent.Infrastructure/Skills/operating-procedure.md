# 操作规程起草

## 先确认
- 设备类型和型号、介质、操作压力和温度
- 规程用途：日常操作、开停车、清洗、应急

## 怎么写
1. 先用 search_documents 查公司已有的操作规程和产品手册，以它为底稿
2. 每一步写：操作、预期现象、异常怎么处理。安全步骤单独标出，不能省
3. 高压釜典型流程（按实际设备调整）：
   - 准备：检查密封面、垫片、仪表、安全阀、冷却水；确认铭牌设计压力和温度
   - 装料和密封：装料不超过规定装料量；螺栓按对角顺序分几次拧紧
   - 试漏：用氮气充到试漏压力，保压检查
   - 置换：用氮气置换釜内空气（一般 3 次以上），涉及氢气的必须置换
   - 升温升压和反应：按规定速率升温，不超过设计压力和温度，记录数据
   - 降温泄压：停止加热，降到安全温度，按规程缓慢泄压，尾气排到安全处
   - 开釜和清洗：确认压力为零、温度安全后再开釜
4. 应急：超温、超压、泄漏、停电、停冷却水时怎么处理

## 常见的坑
- 没泄压就松螺栓
- 含氢系统用空气置换
- 升温速率太快，密封和温度控制跟不上

## 该查什么
search_documents（已有规程、产品手册、事故案例）· show_block（steps、checklist）

## 回答怎么写
安全提示（callout）→ show_block 的 steps 写操作步骤（title 操作、detail 说明、expect 预期现象）→ 开车前检查清单（checklist）→ 应急处理 → 提醒「以设备说明书和公司安全规程为准」
