# 反应热安全评估

## 先确认
- 反应和反应热 ΔH（kJ/mol）：用户给的、文献查的、还是估算的；有反应量热（RC1）数据优先
- 限量反应物浓度（mol/L）、反应液密度（kg/L）、比热（kJ/(kg·K)），或直接给单位质量反应热（kJ/kg）
- 工艺温度 Tp；加料方式：一次全投，还是滴加（滴加时最大累积度多少）
- MTT：敞口是溶剂沸点；密闭釜是设备允许的最高温度，或泄放设定压力对应的温度
- TD24：物料分解 24 小时达到最大速率的温度，要 DSC / ARC 实测

## 怎么做
1. 缺的物性用 run_python 查（thermo、CoolProp 查溶剂密度和比热），写明是查的
2. ΔH 没有数据时，按「化学与反应」技能用生成焓估算，写明是估算
3. TD24 没有实测就不写进组件，不要凭经验估；回答里说明「缺 TD24，需要做 DSC / ARC」
4. 用 show_block 的 thermal 组件：绝热温升、MTSR、等级由系统算；滴加时给 accumulation，一次全投和滴加两种会并排对比
5. 按等级给措施：
   - 1–2 级：常规温度控制、超温报警
   - 3 级：靠溶剂沸腾或泄放兜底，核算冷凝和泄放能力
   - 4 级：可靠的紧急冷却和泄放，温度与加料联锁
   - 5 级：改工艺（滴加、降低浓度、降低累积度），再重新评估
6. 泄放量要按反应失控专门计算（见「安全泄放」技能），不能只按进料量估

## 常见的坑
- 用了一次全投的数据评估滴加工艺，或反过来
- 把 MTT 当成设计温度以外的数随便取
- 忘了反应放出的气体（压力上升比温度上升更快）

## 该查什么
show_block（thermal、formula）· run_python（thermo、CoolProp）· chemical_info · hazard_lookup（是不是重点监管工艺）· search_literature（反应热文献）

## 回答怎么写
结论（几级、主要风险）→ thermal 组件 → 输入数据和来源（哪些是假设）→ 按等级给的措施 → 提醒「估算结果，正式评估要做反应量热和 DSC」
