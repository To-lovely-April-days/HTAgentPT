# 设备数据表与规格书

## 先确认
- 设备类型、位号、数量
- 已知的设计和操作参数；客户有没有指定格式

## 怎么做
1. 用 show_block 的 datasheet：header 放抬头（项目、位号、名称、数量、版次），sections 分块列参数，每块分「设计」「操作」两列，每行写参数名、设计值、操作值、单位、出处
2. 常用分块：
   - 工艺条件：介质、操作压力和温度、流量或容积、物料特性
   - 设计条件：设计压力和温度、腐蚀裕量、焊接接头系数、试验压力、容器类别
   - 材料：筒体、封头、内件、法兰、紧固件、垫片
   - 搅拌和密封：形式、转速、电机功率、密封方式
   - 管口：编号、公称尺寸、压力等级、密封面、用途
   - 检验与验收：无损检测、压力试验、清洁度
3. 参数来源：公司以往项目用 query_projects、search_documents 查；算出来的写计算依据；客户给的写「客户提供」
4. 没有的项写「待定」，不要空着不说

## 常见的坑
- 设计值和操作值混在一起
- 单位不统一（MPa 和 bar、℃ 和 K 混用）
- 压力没写表压还是绝压

## 该查什么
query_projects · search_documents（以往数据表、技术协议）· show_block（datasheet）

## 回答怎么写
一句话说明 → show_block 的 datasheet（可导出 Excel）→ 待定项清单 → 需要客户确认的参数
