# 外形图和三维模型

## 先确认
- 设备：内径、直边段长度、封头（第一版按 2:1 椭圆封头画）
- 夹套：有没有、夹套间隙、覆盖的高度范围
- 管口：每个管口的位号、用途、外径、方位角（顶部）或底部，离中心多远
- 支腿高度
- 尺寸从哪来：先用 query_projects、search_documents 查同类产品和以往项目；查不到的问用户，不要编

## 怎么做
1. 用 run_python 调代码解释器里的 htcad：
```python
import htcad
r = htcad.vessel('30L加氢釜', D=300, L=420, jacket=(30, 60, 420),
    nozzles=[('N1', 0, 0, 60, '搅拌轴'), ('N2', 45, 90, 22, '进气口'), ('N3', 135, 90, 22, '压力表'),
             ('N4', 225, 90, 32, '安全阀'), ('N5', 315, 90, 22, '测温口'), ('N6', None, 0, 32, '底部放料')],
    leg_h=180)
print(r)
```
   - jacket=(间隙, 起始高度, 结束高度)，高度从下切线算；没有夹套写 None
   - nozzles 每项：(位号, 方位角°, 离中心 mm, 外径 mm, 用途)；方位角写 None 的画在底部中心
2. 生成两个文件：out/名称外形图.dxf（主视图 + 管口方位图 + 管口表 + 主要尺寸）、out/名称三维模型.step，系统检查后交给用户下载
3. 同时用 show_block 的 equipment 在回答里显示简图和管口表，方便直接看
4. 改：用户说「N4 换成 DN32」「支腿改高 50」就改参数重新生成，文件名不变

## 常见的坑
- 编造没有依据的尺寸
- 管口方位重叠（两个管口同一方位、离中心又一样）
- 把外形图当制造图：壁厚、法兰、支座、焊缝都不在这里

## 该查什么
run_python · query_projects、search_documents（同类产品的尺寸、管口）· show_block（equipment）

## 回答怎么写
一句话说明生成了什么 → 关键尺寸（外形、内径、直边）→ 管口表 → 哪些尺寸是查到的、哪些是用户给的 → 提醒「外形示意，正式图纸以设计出图为准；壁厚按压力容器设计另算」
