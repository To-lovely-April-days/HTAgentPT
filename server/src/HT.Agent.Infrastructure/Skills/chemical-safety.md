# 化工安全与危化品

## 原则
- 安全提示放在回答最前面，用 show_block 的 callout（危险）
- 不给可能造成危险的操作建议；拿不准的写「按安全规程和安全技术说明书执行，咨询安全负责人」

## 先确认
- 介质名称、CAS 号、浓度、数量
- 操作条件：温度、压力、是否密闭、通风情况
- 场所：实验室还是车间，防爆区域划分

## 怎么做
1. 用 chemical_info 查理化性质、闪点、爆炸极限、毒性、危险性分类；用 search_documents 查公司安全规程和安全技术说明书
2. 是否属于危险化学品，以查询结果为准，不凭印象
3. 氢气：爆炸极限宽、点火能量低。强调用氮气置换（一般 3 次以上）、检漏、防静电、尾气排到安全处
4. 高压设备：开釜前确认已泄压、降到安全温度；不超过铭牌的设计压力和温度；安全阀、爆破片按期校验
5. 泄漏处置：先隔离、通风、切断源头，做好个人防护再处理；大量泄漏按公司应急预案（search_documents 查），查不到就提醒立即报告安全负责人

## 常见的坑
- 混放不相容的物料（氧化剂与可燃物、酸与氰化物等）
- 用空气置换含氢系统
- 把实验室小量的做法直接套到中试规模
- 放热反应只看平均温度，不看局部过热和加料速度

## 该查什么
chemical_info · search_documents（安全规程、安全技术说明书、事故案例、应急预案）· search_standards

## 回答怎么写
危险提示（callout）→ 物质关键性质（表格，带出处）→ 操作、储存、处置要点 → 依据的规程和标准 → 需要做专业安全评估的事项
