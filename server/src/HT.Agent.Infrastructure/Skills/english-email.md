# 英文技术邮件与翻译

## 先确认
- 对方是谁（客户、代理商、供应商），往来到哪一步
- 这封邮件要达成什么：回答问题、确认参数、发报价、催回复
- 有没有附件、要引用的协议或报价

## 怎么写
1. 结构：Subject（简短，带项目名或询价号）→ 称呼 → 第一句说目的 → 要点用编号列 → 下一步和时间 → 署名
2. 术语按公司术语表；用 search_documents 找以往的英文协议和邮件，照公司的叫法写
3. 单位用国际单位，必要时括号里附英制，例如 1.6 MPa (232 psi)；压力写清 gauge 还是 absolute
4. 标准编号原样写（GB/T 150、ASME VIII Div.1），不要翻译编号
5. 语气正式、简洁，一句一个意思；避免中式表达（如 "Please kindly find"）
6. 整份文件要翻译时用 translate_file

## 常见的坑
- 别在邮件里承诺价格、交期、质保条款，除非用户明确给了
- 数字、单位、型号照中文原文，翻译时不能改
- 「设计压力」译 design pressure，「工作压力」译 operating pressure，别混
- 「我司」统一用 we，不要 our company 反复出现

## 该查什么
search_documents（以往英文协议、邮件、产品资料）· translate_file（整份文件翻译）
